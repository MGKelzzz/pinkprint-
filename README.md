# PINKPRINT 🩷🐆

Personal growth + self-discovery Android app.

## First working foundation
- Hot pink / black / cheetah-inspired design
- Home dashboard
- Me / self-discovery
- Journal with local persistence
- Goals with local persistence
- Journey timeline
- Coach placeholder ready for a swappable AI provider
- No paid service required for the core app

## Run
1. Install Node.js.
2. `npm install`
3. `npx expo start`

This is the first buildable source foundation, not the finished full feature set.
